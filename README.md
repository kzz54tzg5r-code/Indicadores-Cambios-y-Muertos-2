# Indicadores Cambios y Muertos v8.4 Operativo

Cambios:
- Pestañas en azul marino como ejemplo.
- Usuario muestra nombre de inicio de sesión.
- Alias fijos: Elo/Eloisa e Ivon/Ivonne, más homologación por hoja Plantilla.
- Por Día: sólo filtro calendario; tabla por tienda con ingresos, acondicionadas, ubicadas, pendientes anteayer/ayer, % habilitado y % ubicado; gráfico combinado.
- Semanal: filtro tiendas + Semana ISO, misma estructura que Por Día.
- Mensual: filtro tiendas + mes, misma estructura que Por Día.
- Productividad: filtro calendario para top colaboradores; índice de actividades con filtro calendario y tienda.
- Conversión y recuperación: todas las tiendas, sin filtro de tiendas del proyecto. Regla por Semana ISO + Tienda + ID/Modelo + Color.
- Botones de descarga PDF base en pestañas con indicadores y PDF integral en Dashboard.
- Single file estable: subir app.py, requirements.txt y assets/ si usas logo.
